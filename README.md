# Библиотека книг

Учебный проект: серверное приложение на **Express** с многостраничным интерфейсом (шаблонизатор **EJS**) и REST API для работы с сущностью «книга».

## Возможности

- просмотр списка всех книг;
- страница конкретной книги;
- создание и редактирование книги через формы;
- удаление книги;
- загрузка обложки и файла книги (multer), скачивание файла книги.

## Технологии

- Node.js, Express
- EJS (шаблонизатор)
- multer (загрузка файлов)
- CommonJS-модули

## Структура проекта

```
project/
  server.js               # точка входа: запуск сервера
  package.json
  src/
    app.js                # настройка Express, EJS, роутов, error-handler
    controllers/
      books.js            # контроллеры REST API
      views.js            # контроллеры страниц (render EJS-шаблонов)
    routes/
      books.routes.js     # маршруты API: /api/books
      views.routes.js     # маршруты страниц: /books
    services/             # бизнес-логика (хранилище книг)
    middleware/
      error-handler.js    # централизованная обработка ошибок
      upload.js           # multer: обложка (изображения) + файл книги (pdf, epub, fb2, txt, mobi)
    views/
      index.ejs           # список книг
      view.ejs            # страница книги
      create.ejs          # форма создания
      update.ejs          # форма редактирования
  uploads/
    books/                # загруженные обложки и файлы книг
```

## Запуск

```bash
npm install
node server.js
```

Сервер по умолчанию запускается на порту `3000` (порт можно переопределить переменной окружения `PORT`).

## Маршруты

### Страницы (HTML, EJS)

| Метод | Путь                  | Описание                          |
|-------|-----------------------|-----------------------------------|
| GET   | `/books`              | список всех книг                  |
| GET   | `/books/create`       | форма создания книги              |
| GET   | `/books/:id`          | страница конкретной книги         |
| GET   | `/books/:id/update`   | форма редактирования книги        |
| GET   | `/books/:id/download` | скачивание файла книги            |
| POST  | `/books/create`       | создание книги (multipart/form-data) |
| POST  | `/books/:id/update`   | редактирование книги (multipart/form-data) |
| POST  | `/books/:id/delete`   | удаление книги                    |

### REST API (JSON)

| Метод   | Путь              | Описание                     |
|---------|-------------------|------------------------------|
| GET     | `/api/books`      | получить все книги           |
| GET     | `/api/books/:id`  | получить книгу по id         |
| POST    | `/api/books`      | создать книгу                |
| PUT     | `/api/books/:id`  | обновить книгу               |
| DELETE  | `/api/books/:id`  | удалить книгу                |

## Сущность «книга»

```json
{
  "id": "...",
  "title": "Название",
  "description": "Описание",
  "authors": "Авторы",
  "favorite": false,
  "fileCover": "имя файла обложки (если загружена)",
  "fileBook": "имя файла книги (если загружен)"
}
```

## Загрузка файлов

- обложка — только изображения (jpg, jpeg, png, gif, webp);
- файл книги — pdf, epub, fb2, txt, mobi;
- максимальный размер файла — 10 МБ;
- файлы сохраняются в `uploads/books` с префиксом из временной метки;
- статику из папки `uploads` раздаёт Express (`/uploads`).

## Обработка ошибок

Ошибки контроллеров передаются через `next(error)` в централизованный обработчик `src/middleware/error-handler.js`, подключённый последним в цепочке middleware. Для API отдает JSON с описанием ошибки, статические ошибки (файл не найден и т.п.) — соответствующие HTTP-коды.
